Project Overview:

Built an end-to-end E-commerce Analytics Dashboard using Streamlit and Tableau



Data Processing (brazil\_ecom.py)

Merged multiple datasets (orders, customers, payments, reviews, products)

Cleaned data and handled missing values

Created features: revenue, delivery time, late delivery flag, order trends

Generated final dataset: olist\_tableau\_ready.csv



Dashboard (streamlit\_analysis.py)

Built interactive dashboard with filters (year, category, state)

KPI metrics: revenue, orders, AOV, delivery performance

Visuals: revenue trends, category analysis, state-wise performance

Customer segmentation using RFM analysis

Statistical testing: T-test, Chi-square, ANOVA, Z-test



Deployment

Deployed app using Streamlit Community Cloud

Published Tableau dashboard on Tableau Public



Key Insights

Identified top revenue categories and peak sales periods

Detected late delivery patterns across states

Segmented customers for targeted marketing
